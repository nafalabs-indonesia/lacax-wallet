# Reporting a Vulnerability

The security of LacaX Wallet is extremely important to us.  
We appreciate responsible disclosure from the community and security researchers.

## Preferred Reporting Method

Please use GitHub's **Private Vulnerability Reporting** feature to report security issues privately.

### Report a Vulnerability

[Create a Private Vulnerability Report](https://github.com/nafalabs-indonesia/lacax-wallet/security/advisories/new)

This allows vulnerabilities to be reviewed and resolved before public disclosure.

---

# Responsible Disclosure

Please do not publicly disclose security vulnerabilities until we have had a reasonable opportunity to investigate and release a fix.

We will make a best effort to:
- Acknowledge valid reports quickly
- Investigate and validate the issue
- Release security fixes as soon as possible

---

# Scope

## In Scope

The following types of vulnerabilities are considered in scope:

- Private key or seed phrase leakage
- Weak encryption or insecure key derivation
- Secure storage vulnerabilities
- Password authentication bypass
- WalletConnect session vulnerabilities
- RPC hijacking or chain spoofing
- Transaction spoofing vulnerabilities
- Sensitive data exposure
- Remote code execution
- Critical vulnerabilities affecting user funds

---

## Out of Scope

The following are generally considered out of scope:

- UI or UX bugs
- Feature requests
- Rate limiting issues unless security-critical
- Vulnerabilities affecting third-party services
- Phishing or social engineering attacks
- Issues caused by rooted or compromised devices
- Denial of service attacks with no security impact

# Rewards

Currently, LacaX Wallet does not offer a public bug bounty program.

However, valid and impactful reports may receive:
- Public acknowledgment
- Contributor recognition
- Future consideration for bounty programs
