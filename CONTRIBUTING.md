# Contributing to LacaX Wallet

First of all, thank you for your interest in contributing to LacaX Wallet ❤️

We welcome contributions from the community, whether it's:
- Bug fixes
- Feature improvements
- Documentation updates
- UI/UX improvements
- Security enhancements
- Performance optimizations

---

# Getting Started

## 1. Fork the Repository

Create your own fork of the repository and clone it locally.

```bash
git clone https://github.com/nafalabs-indonesia/lacax-wallet.git
```

---

## 2. Install Dependencies

```bash
npm install
```

or

```bash
yarn install
```

---

## 3. Start Development Server

```bash
npx expo start
```

---

# Development Guidelines

Please follow these guidelines before submitting a pull request:

- Write clean and readable code
- Use consistent formatting
- Keep pull requests focused and minimal
- Test your changes before submitting
- Avoid committing sensitive data or secrets
- Never include private keys or seed phrases in commits

---

# Branch Naming

Recommended branch naming:

```text
feature/add-swap-screen
fix/walletconnect-session
docs/update-readme
```

---

# Pull Requests

Before opening a pull request:

- Ensure the app builds successfully
- Ensure there are no linting issues
- Clearly describe the purpose of the PR
- Link related issues if applicable

---

# Reporting Bugs

If you find a bug, please open an issue with:

- Clear description
- Steps to reproduce
- Expected behavior
- Screenshots if applicable
- Device / OS information

---

# Security Issues

Please do NOT open public issues for security vulnerabilities.

Instead, use GitHub's private vulnerability reporting feature:

https://github.com/nafalabs-indonesia/lacax-wallet/security/advisories/new

For additional information regarding vulnerability reporting, disclosure policy, and security scope, please read our Security Policy:

[SECURITY.md](./SECURITY.md)

---

# Code of Conduct

By participating in this project, you agree to maintain a respectful and constructive environment for everyone.
