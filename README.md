## About

Lacax Wallet is a modern crypto wallet built with React Native and Expo, designed to make digital asset management simple, secure, and accessible.

---

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router

---

## Installation

Clone the repository:

```bash
git clone https://github.com/nafalabs-indonesia/lacax-wallet.git
```

Enter the project directory:

```bash
cd lacax-wallet
```

Install dependencies:

```bash
npm install
```

---

## Running the App

Start the development server:

```bash
npx expo start
```

Run on Android:

```bash
npx expo run:android
```

Run on iOS:

```bash
npx expo run:ios
```

Run on Web:

```bash
npx expo start --web
```

---

## Build with Expo

Install EAS CLI:

```bash
npm install -g eas-cli
```

Login to Expo:

```bash
eas login
```

Configure EAS Build:

```bash
eas build:configure
```

Build Android APK:

```bash
eas build -p android --profile preview
```

Build Android App Bundle:

```bash
eas build -p android --profile production
```

Build iOS:

```bash
eas build -p ios --profile production
```
